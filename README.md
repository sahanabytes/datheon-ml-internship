# Datheon Machine Learning and Data Science Internship

This repository contains projects completed as part of the Datheon Machine Learning and Data Science Internship.

## Task 1: Iris Flower Classification

### Objective
Build machine learning models to classify iris flowers into three species using the Iris dataset.

### Dataset
The Iris dataset contains 150 samples, four numerical features, and three flower species:
- Setosa
- Versicolor
- Virginica

### Models Used
- Logistic Regression
- Decision Tree Classifier

### Data Preprocessing
- Explored the dataset and checked for missing values.
- Split the data into training and testing sets (80:20).
- Applied feature scaling using StandardScaler.

### Evaluation
Both models achieved **93.33% test accuracy** in this experiment. Precision, recall, F1-score, classification reports, and confusion matrices were also used to evaluate performance.
